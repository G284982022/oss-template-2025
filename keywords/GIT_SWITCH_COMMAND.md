# git switch コマンド

## 説明
git switchコマンドは、ブランチを切り替えるための新しいコマンドで、Git バージョン 2.23 から導入されました。
以前はcheckoutコマンドにもブランチ切り替え機能が含まれていましたが、checkoutは多機能で混乱を招くことがあったため、機能を分離してswitchコマンドとして提供されるようになりました。

また、同じバージョンで、ファイルの変更を取り消すためのrestoreコマンドも追加されており、役割がより明確になっています。

使用例
次のコマンドを実行すると、作業用ブランチに切り替えられます。
git switch feature/new-ui
